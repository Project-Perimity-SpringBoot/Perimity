## What shipped today

- **Returning students keep their own roll number.** Validation resolves the
  sheet's emails to account ids through `GET /api/internal/auth/users/by-email`
  — an endpoint that already existed, so no new DTO and no change to
  auth-service. Proven on batch 19: rows that were rejected as collisions now
  import as `UPDATED`.
- **Every imported student is told their account exists.** A reused row used to
  get nothing at all. The temporary password is reissued only when
  `must_change_password` is still true, so a student who has set their own
  password keeps it.
- **Pass, pass email, welcome email and in-app card** redesigned in deep
  indigo-violet and made consistent, with the holder's photo on the card.
- **Drive photos work.** `supportsAllDrives` was missing on both file calls.
  Without it the API returns a flat 404 for Shared Drive files — the same answer
  it gives for a file that was never shared — so a correctly shared folder
  failed identically to an unshared one.
- **Flyway** in user-service and gatepass-service, baselined and verified both
  ways: existing databases stamp at V1 without executing, an empty database
  builds all 7 tables from V1.
- **Counts refresh after an import.** `confirm` invalidated only the batch, so
  every other screen kept serving cached data.
- **Faculty overview** gained a stats row and a Recent student imports panel.
